# SAMI Star-Forming Galaxy Morphology Pipeline

Computes four non-parametric morphology metrics - Gini coefficient of Hα
emission, Concentration, Asymmetry, and Smoothness (CAS) - for SAMI
star-forming galaxies, and merges them with Wang et al.'s SFR/Mstar
classification and GAMA environment catalogues into one master table.

This folder is a clean rebuild of an earlier working repo. See
`AUDIT_REPORT.md` for the diagnostic that drove the rebuild and
`CHANGELOG.md` for exactly what changed and why (most importantly: the Gini
formula was wrong and has been corrected - every number in this folder was
regenerated from source, nothing was hand-edited).

## Layout

```
data/
  raw/          symlinks to the original raw Hα cubes + continuum maps
                (not duplicated - see note below)
  masked/       continuum-masked Hα + continuum FITS, generated by 02
  catalogues/   Wang's SAMI_CIndex_data txt files + GAMA pairs/morphology
                FITS (symlinked, not duplicated)
src/
  01_flux_map.py         plot one galaxy's raw Hα flux map
  02_continuum_mask.py   build the shared continuum mask -> data/masked/
  03_metrics/
    gini.py               corrected Gini (Lotz 2004)
    concentration.py       Wang CIndex table
    asymmetry.py            Conselice A
    smoothness.py           partial Conselice S
  04_build_master_csv.py  merges everything into one master table
  05_sfms.py              fits the star-forming main sequence, adds delta_ms
  utils/                  shared I/O, masking, units, Wang-catalogue, sfms,
                           plotting helpers - the single implementation of
                           each, used by every script above
outputs/
  csv/       one CSV per stage + outputs/csv/master_<date>.csv +
             outputs/csv/master_sfms_<date>.csv (master + delta_ms)
  figures/   flux maps etc.
notebooks/   exploratory only - nothing here feeds back into src/
archive/     superseded/duplicate/scratch code, kept with notes
             (see archive/README.md) rather than deleted
```

`data/raw/` and `data/catalogues/` are symlinks into the original repo's
`data/` folder, not copies - the raw FITS alone are >1.5 GB and there is no
reason to duplicate them. If you move this folder to share it standalone,
either copy the real files into `data/raw/`+`data/catalogues/` in place of
the symlinks, or ship both folders together.

## Running the full pipeline

Requires: `astropy`, `numpy`, `pandas`, `scipy`, `matplotlib`, `tqdm` (Python
3.11 tested).

From this folder (`sami_sf_pipeline/`):

```bash
# 1. Build the shared continuum mask for every galaxy (~2340 galaxies, ~1 min)
python src/02_continuum_mask.py

# 2. Compute each metric over the full sample
python src/03_metrics/gini.py
python src/03_metrics/concentration.py     # run before smoothness.py - it needs r_e
python src/03_metrics/asymmetry.py         # ~2 min
python src/03_metrics/smoothness.py

# 3. Merge everything into the master table
python src/04_build_master_csv.py

# 4. Fit the star-forming main sequence and add delta_ms
python src/05_sfms.py
```

This writes `outputs/csv/master_<today's date>.csv`, and then
`outputs/csv/master_sfms_<today's date>.csv` (the same table plus a
`delta_ms` column), `sfms_fit_params_<date>.csv` (fitted S0/a1/Mt), and
`sfms_ridge_points_<date>.csv` (the per-mass-bin points the fit was
anchored on - handy for overplotting). Re-running steps 3-4 on a different
day produces new dated files rather than overwriting the previous ones - if
you want a previous run's exact output, keep the file, don't rely on
rerunning to reproduce it (inputs will match, but the filename won't).

`05_sfms.py` defaults to the most recent `master_<date>.csv` in
`outputs/csv/`; pass `--input` to point it at a specific one.

Re-running any script is always safe: every stage reads from disk and
writes a fresh CSV, nothing is patched in place.

## Running for a single galaxy

Every script accepts `--catid` to run/print a single galaxy without writing
the full-sample CSV (useful for spot-checking or debugging one object):

```bash
python src/01_flux_map.py --catid 7139
python src/02_continuum_mask.py --catid 7139
python src/03_metrics/gini.py --catid 7139
python src/03_metrics/asymmetry.py --catid 7139
python src/03_metrics/smoothness.py --catid 23117   # must exist in concentration.csv first
```

`03_metrics/concentration.py` and `04_build_master_csv.py` always process
the full Wang catalogue (there's no meaningful "single galaxy" mode for a
catalogue merge) - look the CATID up in the resulting CSV instead.

## Pipeline order and dependencies

```
02_continuum_mask.py
        │
        ├──► 03_metrics/gini.py ────────┐
        ├──► 03_metrics/asymmetry.py ───┤
        │                               │
03_metrics/concentration.py             │
        │                               │
        └──► 03_metrics/smoothness.py ──┤   (needs r_e from concentration.csv)
                                         │
                              04_build_master_csv.py
                                         │
                              outputs/csv/master_<date>.csv
                                         │
                                   05_sfms.py
                                         │
                          outputs/csv/master_sfms_<date>.csv
```

`concentration.py` doesn't depend on `02_continuum_mask.py` at all - it
reads Wang's catalogue directly and can be run any time. Everything else
that touches Hα/continuum flux maps depends on `02` having been run first.

## What each metric actually measures (and where it comes from)

- **G (Gini)** - computed by this pipeline from the continuum-masked Hα
  and continuum flux maps, using the Lotz (2004) astronomy convention.
- **C (Concentration)** - *not* computed by this pipeline. It's
  `log10(r50,Hα / r50,continuum)`, taken directly from Wang et al.'s
  external `SAMI_CIndex_data` catalogue, computed on their own
  (differently masked/apertured) reduction. See
  `archive/external_wang_pipeline/` for how it was originally derived.
- **A (Asymmetry)** - computed by this pipeline from the continuum-masked
  Hα map, following Conselice (2003) eq. 1, with a grid-search minimisation
  over rotation centre. No background-asymmetry term is subtracted (see
  `AUDIT_REPORT.md` section 3.4 for why that's a documented simplification,
  not an oversight).
- **S (Smoothness)** - computed by this pipeline from the continuum-masked
  Hα map. This is a *partial* clumpiness statistic: no background-smoothness
  term and no central-pixel exclusion, both left as-is per the audit review
  (see `CHANGELOG.md`) - it is not the full Conselice S.
- **delta_ms (SFMS offset)** - computed by `05_sfms.py`: the star-forming
  main sequence ridge line is fit (Lee et al. 2015 turnover form, fit to the
  peak of the log(SFR) histogram per mass bin), and `delta_ms` is each
  galaxy's vertical log(SFR) offset from that fitted line. `delta_ms > 0`
  means elevated star formation relative to the ridge, `< 0` means
  suppressed.

## Finding example galaxies on/above/below the SFMS

`notebooks/sfms_explorer.ipynb` plots log(M*) vs log(sSFR) for Wang's
catalogue with the fitted SFMS + on-MS band overlaid, and highlights any
CATID(s) you list in its config cell (with a classification + `delta_ms`
table underneath). Requires `05_sfms.py` to have been run at least once.

`notebooks/flux_map_fixed_scale.ipynb` plots the raw Hα flux map for one or
more galaxies (same data as `01_flux_map.py`) using a **fixed** colour
scale (`FLUX_VMIN`/`FLUX_VMAX` in its config cell) instead of auto-scaling
each galaxy to its own min/max - so absolute Hα brightness is directly
comparable between galaxies, e.g. for a thesis figure showing how active
star formation actually differs above/on/below the SFMS. Its comparison
panel defaults to the same three example CATIDs as `sfms_explorer.ipynb`
and pulls their `delta_ms` labels from it if that notebook has been run.
